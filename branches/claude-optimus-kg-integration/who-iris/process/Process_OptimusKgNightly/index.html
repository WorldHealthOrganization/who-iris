summaryEvery night after the IRIS CDN release is published: select the changed items an editor's scope of interest asks for, publish a work order for the Zitnik lab, which runs GuidelineKG on its own keys, then verify the lab's result release, project it through the…
descriptionEvery night after the IRIS CDN release is published: select the changed items an editor's scope of interest asks for, publish a work order for the Zitnik lab, which runs GuidelineKG on its own keys, then verify the lab's result release, project it through the crosswalk and adjudicate it against the L1 KG. The existing L1 ingestion is unchanged; this path runs beside it. A night on which the lab publishes nothing ends as awaiting-extractor, never as a failure, and never blocks the CDN release.
